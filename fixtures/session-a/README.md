# Sesión A — cambio no pedido

**Pedido:** modificar un solo componente (por ejemplo `Button.tsx`).

**Lo que hace el agente (simulado):** también toca otro archivo ajeno (`Modal.tsx`).

**Criterios:** AC4, AC5 — el borrador debe marcar `Modal.tsx` como fuera de lo pedido y cubrir el 100 % de archivos del diff.
